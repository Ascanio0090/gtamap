# 🗺️ GTA Map - Progressive Web App

Una mappa interattiva per GTA sviluppata come Progressive Web App (PWA), ottimizzata sia per desktop che per dispositivi mobili.

## 🚀 Funzionalità
- **Installabile come PWA:** Funziona anche offline grazie al Service Worker (`sw.js`).
- **Interfaccia reattiva:** Adatta a schermi di varie dimensioni.
- **Icone personalizzate:** Supporto completo per l'installazione su schermata Home.

## 🛠️ Tecnologie Utilizzate
- HTML5 / CSS3 / JavaScript
- Service Workers & Web App Manifest
